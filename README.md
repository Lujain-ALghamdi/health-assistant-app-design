A mobile app design concept for a personal health assistant — covering onboarding, medication guidance, appointment scheduling, and in-app chat with a health assistant, designed end-to-end in Figma as a complete UX flow.

> **Note:** this repository contains the **design deliverables** for the concept (flows, mockups, and screens). It does not include a built/running application.

## Overview

Health Assistant is a mobile app concept designed to give users a single, simple place to manage everyday health tasks: getting quick medication guidance, keeping track of prescriptions and reminders, booking appointments, and messaging a health assistant for general advice. The design work covers the full user journey — from sign-up through daily use — with a consistent visual language across every screen.

## Key Features

- **Onboarding** — welcome, sign-up, and login screens with a clear, guided entry flow
- **Home dashboard** — a single hub linking to medication suggestions, appointments, medication tracking, and the health assistant chat
- **Medication suggestions** — a symptom-intake form (symptom, duration, intensity, notes) that returns guidance, with a built-in prompt to consult a doctor for anything beyond general advice
- **Appointment booking** — calendar-based date/time selection with instant booking confirmation
- **Chat with health assistant** — a conversational interface for general health questions and tips
- **Medication reminders & schedule management** — a reminder list with toggles and an editable daily schedule

## Viewing the Design

This is a design repository rather than a codebase, so there's nothing to install or run. Open `assets/design-overview.png` to see the complete flow, or browse the individual screen groups below.

## Screens

The flow covers: **Welcome → Sign Up / Login → Home Dashboard → Medication Suggestions → Appointment Booking → Chat with Health Assistant → Medication Reminders → Schedule Management**, with every screen connected to show how a user moves through the app.
